# Travel Explorer

A destination explorer covering 30 places around the world. Each place has a type (Historical, Beach, City or Nature), country, rating, price, image and description.

**Live Demo:** https://martinafarah6.github.io/travel_explorer/

## Features

- 30 destinations with type, country, rating and price
- Details view for each destination
- Favorites for each destination

## Tech Stack

- React
- JavaScript, CSS
- Deployed on GitHub Pages

## Run Locally

```bash
git clone https://github.com/martinafarah6/travel_explorer.git
cd travel_explorer
npm install
npm start
```
